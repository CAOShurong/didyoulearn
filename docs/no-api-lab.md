# No-API community lab

The community lab lets people compare subscription products without giving DidYouLearn credentials.

## Workflow

1. Export a task packet.
2. Open the declared product and mode.
3. Start a new conversation and paste the teaching brief.
4. Complete the interaction within the task's time and turn limits.
5. Save the transcript locally.
6. Complete the post-test without consulting the transcript or the AI.
7. Export a run bundle.

## Limitation

The participant knows which product they opened, and the project cannot cryptographically prove
that a pasted transcript came from that product. These runs are useful personal evidence and
community signals, but they are not equivalent to a coordinator-controlled blind trial.
